# ⚽ MatchPulse

## AI-Powered Football Intelligence Platform

MatchPulse transforms synthetic football match events into real-time insights, explainable narratives, personalized fan experiences, and automated match recaps.

Built for the Microsoft Premier League Hackathon, MatchPulse helps fans, analysts, broadcasters, and studios understand not only what happened during a match, but why it mattered.

---

## 📌 Problem Statement

Football fans often see statistics such as possession, shots, and goals, but they rarely receive clear explanations of how those events influence the game.

Broadcasters and analysts need real-time intelligence that transforms raw football events into meaningful stories and contextual insights.

---

## 🚀 Solution

MatchPulse ingests synthetic football events and converts them into explainable match intelligence through a multi-agent workflow.

The platform:

- Ingests synthetic match events
- Generates match statistics
- Explains key moments
- Creates AI-powered narratives
- Personalizes insights for different audiences
- Produces automated match recaps
- Supports multi-language storytelling

# 🤖 Multi-Agent Workflow

## Event Agent

Processes incoming synthetic football events such as:

- Passes
- Shots
- Goals
- Tackles
- Possession changes

## Stats Agent

Calculates:

- Possession %
- Pass Accuracy %
- Goal Count
- Shot Count
- Pressure Index

## Narrative Agent

Generates real-time match stories such as:

> Blue FC is controlling the game through sustained possession and attacking momentum.

## Explainability Agent

Explains why moments matter:

> The goal resulted from a prolonged passing sequence and increased attacking pressure.

## Personalization Agent

Provides multiple viewing modes:

### Analyst Mode

Detailed statistics and metrics.

### Fan Mode

Simple and engaging explanations.

### Player Mode

Player-focused insights and performance summaries.

## Recap Agent

Generates automated full-time match summaries.
