# MatchPulse

AI-powered football intelligence platform that transforms synthetic football events into:

- Match Intelligence
- AI Narratives
- Explainable Insights
- Personalized Fan Experiences
- Automated Match Recaps

## Architecture

Event Agent
↓
Stats Agent
↓
Narrative Agent
↓
Explainability Agent
↓
Personalization Agent
↓
Recap Agent
